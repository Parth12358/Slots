# slots

A local coordinator for Claude Code sessions and the heavy work they run.

- Manual: https://parth12358.github.io/Slots/wiki/, or offline with `slots help` and `man slots`
  (after `slots man --install`).
- For agents: `slots help agents`, or the whole manual as text at
  https://parth12358.github.io/Slots/wiki/all.txt.
- Design: [docs/design.md](docs/design.md).

```bash
uv tool install git+https://github.com/Parth12358/Slots@prod
slots init && slots help quickstart
```
